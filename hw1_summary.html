模組 1 題源：作業一 1(a)
Ch. 1-2 完善保密與正確性約束

運算子改換與單射要求（AND 運算的資訊毀滅性）

直觀秒懂大腦模型：黑色油漆效應
AND 運算就像刷上一層黑色油漆。只要金鑰給了 0，無論你的秘密是 0 還是 1，塗上去全部變成 0。資訊一旦被毀滅，解密端就絕無可能逆向還原，因此解密正確性破功；同時，若攻擊者在密文中截獲 1，他立刻能斷定明文絕不可能是 0（因為 0 AND 任何數都無法湊出 1），機密當場洩漏，保密性立刻瓦解。
數學本質：單射（Injectivity）是正確性的命脈

解密正確性定義為 $\text{Dec}(K, \text{Enc}(K, M)) = M$ 恆成立。這意味著對任意固定的金鑰 $k$，加密函數 $f_k(m) = \text{Enc}(k, m)$ 必須為單射映射（Injective Function）。
布林 AND 運算於 $k=0$ 時產生映射碰撞： $$0 \wedge 0 = 0 \quad \text{且} \quad 0 \wedge 1 = 0$$ 兩不同明文映射至同一密文，逆函數不存在，因此不具備解密正確性。

保密性判定：條件機率不相等

夏農完善保密性要求密文出現的機率與明文完全獨立。檢驗密文 $C=1$ 之條件機率： $$\Pr[C = 1 \mid M = 0] = \Pr[K \wedge 0 = 1] = 0$$ $$\Pr[C = 1 \mid M = 1] = \Pr[K \wedge 1 = 1] = \Pr[K = 1] = \frac{1}{2}$$ 由於 $0 \neq \frac{1}{2}$，違反獨立性，因此不具備完善保密性。

考場作答一秒速記：
正確性反例：$k=0 \implies \text{Enc}(0, 0) = \text{Enc}(0, 1) = 0$（非單射不可逆）
保密性反例：$\Pr[C=1 \mid M=0] = 0 \neq \frac{1}{2} = \Pr[C=1 \mid M=1]$（條件機率不等）
模組 2 題源：作業一 1(b)
Ch. 1-2 有限群論與均勻性保持

有限群模運算 OTP（模 10 加法與加法反元素之唯一性）

直觀秒懂大腦模型：鐘面撥針模型
想像一個 10 格的時鐘（數字 0 到 9）。加密就是從明文起點順時針撥動 $K$ 格，解密就是逆時針撥回 $K$ 格，必定回到原點，這就是解密正確性；若金鑰 $K$ 是由完全公正的十面骰子均勻擲出，那麼不論起點是指向幾號，指針最終停在任何一格的機率都是完全相等的 $\frac{1}{10}$。偷看終點對猜測起點毫無幫助，這就是完善保密性。
正確性推導：反元素抵消

在整數模 10 算術加法群 $(\mathbb{Z}_{10}, +)$ 中： $$\text{Dec}(K, \text{Enc}(K, M)) = ((K + M) \bmod 10 - K) \bmod 10$$ $$= (K + M - K) \bmod 10 = M \bmod 10 = M$$ 運算閉合且精確抵消，解密正確無誤。

保密性證明：同餘方程唯一解

對任意固定明文 $m \in \mathbb{Z}_{10}$ 與密文 $c \in \mathbb{Z}_{10}$： $$\Pr[C = c \mid M = m] = \Pr[(K + m) \bmod 10 = c]$$ 在阿貝爾群 $\mathbb{Z}_{10}$ 中，同餘式 $K \equiv c - m \pmod{10}$ 存在唯一整數解 $k^* = (c - m) \bmod 10$。因為 $K$ 均勻分佈於 $\{0, \dots, 9\}$，得： $$\Pr[K = k^*] = \frac{1}{10}$$ 條件機率恆為 $\frac{1}{10}$，與明文完全無關，達成完善保密性。

考場作答必備得分關鍵句：
「因為 $\mathbb{Z}_{10}$ 為有限阿貝爾群，每個元素皆具唯一加法反元素，方程式 $K \equiv c - m \pmod{10}$ 在金鑰空間中存在唯一解，故 $\Pr[C=c \mid M=m] = \frac{1}{10}$。」
模組 3 題源：作業一 1(c)
Ch. 1-2 金鑰重用破綻（Two-Time Pad）

前後加密與金鑰長度不足（Two-Time Pad 差分消除攻擊）

直觀秒懂大腦模型：兩張半透明紙重疊相消
加密兩段訊息卻共用同一把鑰匙。攻擊者將前後兩段密文拿來做 XOR 運算，金鑰與自身相消（$K \oplus K = 0$），遮罩瞬間人間蒸發，直接露出兩份明文的差距。就像把兩張印了雜訊的半透明紙疊在一起，雜訊相互抵消，浮現出兩份公文的差異輪廓。
差分消除基本算式：
$$C_1 \oplus C_2 = (K \oplus M_1) \oplus (K \oplus M_2) = (K \oplus K) \oplus (M_1 \oplus M_2) = M_1 \oplus M_2$$
攻擊者可萃取的 4 大資訊維度：
  • 位元差分值（Bitwise Difference）：直接掌握兩段明文在哪些位元上相同、哪些位元上相異。
  • 明文重複性洩漏（Redundancy Detection）：若前後兩段明文相同（$M_1 = M_2$），則密文差分必為全零字串：$C_1 \oplus C_2 = 0^n$。
  • 已知標頭破譯（Crib Dragging）：若協定前段為固定格式（已知 $M_1$），可直接無痛還原後段秘密：$M_2 = (C_1 \oplus C_2) \oplus M_1$。
  • 區分挑戰勝率 100%：提交 $M^{(0)} = (0^n, 0^n)$ 與 $M^{(1)} = (0^n, 1^n)$，檢驗 $C_1 \oplus C_2 \stackrel{?}{=} 0^n$，優勢 $\mathbf{Adv} = 1$。
模組 4 題源：作業一 2(a), 2(b)
Ch. 2 函式庫不可區分性（Library Indistinguishability）

函式庫判定雙雄：等價化簡 vs 跨查詢一致性區分

狀況 A：完全等價不可區分（作業 2a） $\mathcal{L}_1 \equiv \mathcal{L}_2$

大腦模型：精心設計的障眼法。看表面程式碼有 if/else 分支，實際上 if 裡外的值完全一樣。

當 $M = R_1$ 時代入 else 公式：
$M \oplus R_1 \oplus R_2 = R_1 \oplus R_1 \oplus R_2 = 0^n \oplus R_2 = R_2$

核心邏輯：if 分支完全冗餘，整台機器無論輸入什麼，永遠都在回傳 $M \oplus (R_1 \oplus R_2)$。令 $K' = R_1 \oplus R_2$，根據 OTP 獨立隨機數相加性質，$K'$ 亦為純隨機字串。故 $\mathcal{L}_2$ 行為與 $\mathcal{L}_1$（回傳 $M \oplus K$）完全等價，I/O 分佈完全一致。

狀況 B：可區分攻破（作業 2b） $\mathcal{L}_C \not\equiv \mathcal{L}_D$

大腦模型：真金不怕火煉，冒牌貨開箱吐香蕉。$\mathcal{L}_C$ 鎖著真實金鑰，放蘋果進去開箱必定還是蘋果；$\mathcal{L}_D$ 只是每次隨機吐數的無腦發牌機。

區分器程式 $D$：
1. 呼叫 $C := \text{enc}(0^n)$
2. 呼叫 $M' := \text{dec}(C)$
3. 若 $M' == 0^n$ 輸出 1；否則輸出 0

優勢計算：
在 $\mathcal{L}_C$ 中，$\text{dec}(\text{enc}(0^n)) = 0^n$ 恆成立，勝率為 1；在 $\mathcal{L}_D$ 中，$\text{dec}$ 獨立隨機抽樣，命中 $0^n$ 機率為 $2^{-n}$。
$$\mathbf{Adv} = |1 - 2^{-n}| \approx 1$$

Ch. 2 單次保密性（One-Time Secrecy / IND-OTS）

單次保密性推導（$\Sigma'$ 派生密文固定差分安全分析）

直觀秒懂大腦模型：影子模型
雖然這個方案一口氣產出兩個密文 $(C_1, C_2)$，且第二個密文固定是第一個密文的逐位元反轉（$C_2 = C_1 \oplus 1^n$）。但只要第一個密文 $C_1 = K \oplus M$ 本身是完美的均勻隨機亂碼，第二個密文就只是隨機數的影子。只要金鑰只用一次，對於任何明文，密文對永遠都是「一個均勻隨機字串 + 它的反轉」，完全不依賴於明文內容，因此依然達成單次完善保密。
考場辨析心法：差分常數 vs 差分明文
差分與明文無關（安全）： 若密文差分 $C_1 \oplus C_2 = \Delta$ 為與明文無關的固定常數（如 $1^n$），密文對聯合分佈不隨明文改變，單次保密性依然成立。
差分包含明文差（破功）： 若密文差分 $C_1 \oplus C_2 = M_1 \oplus M_2$（金鑰相消），則密文差分直接洩漏明文資訊，保密性徹底崩潰。
模組 6 題源：作業一 4(a), 4(b)
Ch. 5-6 偽隨機生成器與偽隨機函數檢驗

PRG 與 PRF 安全檢驗（種子洩漏與線性差分攻擊）

PRG 串接禁忌：輸出不可公開種子

構造 $H(S) = A \parallel B \parallel C \parallel D$，其中 $A \parallel B = G(S)$ 且 $C \parallel D = G(B)$。
致命傷：中間狀態種子 $B$ 被直接暴露在第二個區塊！
區分器演算法： 輸入 $W = w_1 \parallel w_2 \parallel w_3 \parallel w_4$。區分器本地重新執行 $G(w_2)$，比對是否等於 $w_3 \parallel w_4$。若是輸出 1，否則輸出 0。
$$\Pr[D(H(S)) = 1] = 1 \quad \text{vs} \quad \Pr[D(\text{Random}) = 1] = 2^{-2\lambda}$$ 優勢 $\mathbf{Adv} = 1 - 2^{-2\lambda} \approx 1$，一秒識破。

PRF 非線性要求：線性構造必死

構造 $F(K, X) = G(K) \oplus X$。
致命傷：純線性操作導致金鑰項在差分中被完全消去： $$F(K, X_1) \oplus F(K, X_2) = (G(K) \oplus X_1) \oplus (G(K) \oplus X_2) = X_1 \oplus X_2$$ 區分器演算法： 查詢 $X_1 = 0^n$ 得 $Y_1$，查詢 $X_2 = 1^n$ 得 $Y_2$。檢驗 $Y_1 \oplus Y_2 \stackrel{?}{=} 1^n$。
真實 PRF 滿足率為 1；真隨機函數輸出獨立，滿足率僅為 $2^{-n}$。優勢 $\mathbf{Adv} \approx 1$。

Ch. 8 選擇明文安全（IND-CPA Security）

選擇明文安全（CPA）4 大經典架構檢測準則

加密方案構造 CPA 安全性 核心判斷機制與因果邏輯 考場破譯/得分點
$(R, F(K, R) \oplus M)$ CPA 安全 隨機數 $R$ 做為 PRF 的輸入。只要 $R$ 不碰撞（生日界限 $\frac{q^2}{2^\lambda}$），每次加密皆使用全新獨立的偽隨機遮罩。 標準隨機化 PRF 加密
$(R, F(K, M) \oplus R)$ CPA 潰敗 隨機數 $R$ 放在最外層！前後兩半 XOR 直接相消：$C_1 \oplus C_2 = R \oplus (F(K, M) \oplus R) = F(K, M)$，完全喪失隨機化保護。 差分消去 $R$，優勢 $\approx 1$
AES in ECB 模式 CPA 潰敗 決定性加密（Deterministic Encryption）。相同明文區塊永遠產出相同密文區塊，無法抵抗多區塊重現攻擊。 提交相同區塊比對重複性
AES in CTR（隨機 IV） CPA 安全 隨機選擇初始 IV。在生日界限之查詢量內，計數器輸入空間不重疊，金鑰串流不可區分於真隨機。 串流加密標準範例

二、 考場奪分必備：四大萬用證明推導藍圖

標準化作答框架，直接套用即可確保邏輯閉環與拿滿所有推導步驟分數

藍圖 1：完善保密性展開三步法 適用：保密性充要條件與 OTP
【步驟 1：寫出保密核心等式】 $$\Pr[M = m \mid C = c] = \Pr[M = m]$$
【步驟 2：利用貝氏定理反轉】 $$\Pr[M = m \mid C = c] = \frac{\Pr[C = c \mid M = m] \cdot \Pr[M = m]}{\Pr[C = c]}$$
【步驟 3：兩邊消去導出充要條件】 代入後消去 $\Pr[M = m] > 0$，直接導得： $$\Pr[C = c \mid M = m] = \Pr[C = c]$$ 對任意兩筆明文 $m_0, m_1$，必定滿足 $\Pr[C=c \mid M=m_0] = \Pr[C=c \mid M=m_1]$。
藍圖 2：區分器演算法與優勢標準模版 適用：函式庫判定、PRG/PRF 破譯
【步驟 1：定義查詢策略】 查詢 Oracle 特定值（例如差分明文對 $X_1 = 0^n, X_2 = 1^n$ 或串聯查詢 $\text{enc}$ 後 $\text{dec}$）。
【步驟 2：設計輸出判定準則】 若回傳結果滿足目標不變量（如 $Y_1 \oplus Y_2 == 1^n$），輸出 1；否則輸出 0。
【步驟 3：優勢精確計算】 $$\mathbf{Adv}_D = |\Pr[D^{\text{Real}} = 1] - \Pr[D^{\text{Rand}} = 1]|$$ $$= |1 - 2^{-n}| \approx 1 \quad (\text{不可忽略，安全性破功})$$
藍圖 3：線性差分消除驗證公式 適用：Two-Time Pad、線性 PRF
【步驟 1：列出密文或輸出向量】 $$C_1 = K \oplus M_1, \quad C_2 = K \oplus M_2$$
【步驟 2：執行差分運算消去金鑰】 $$C_1 \oplus C_2 = (K \oplus M_1) \oplus (K \oplus M_2) = (K \oplus K) \oplus (M_1 \oplus M_2) = M_1 \oplus M_2$$
【步驟 3：構造區分明文完成閉環】 提交 $M_0 = (0^n, 0^n)$ 與 $M_1 = (0^n, 1^n)$，利用差分是否為 $0^n$ 達到 100% 區分。
藍圖 4：反例構造與抽屜原理否定模版 適用：證非單射、證金鑰空間下界
【步驟 1：反設金鑰數量少於明文】 假設 $|\mathcal{K}| < |\mathcal{M}|$。隨機固定合法密文 $c$（$\Pr[C=c] > 0$）。
【步驟 2：抽屜原理解密空間上限】 因為解密為確定性函數，能解出的明文集合 $S(c)$ 滿足 $|S(c)| \le |\mathcal{K}| < |\mathcal{M}|$。
【步驟 3：抓出零機率明文製造矛盾】 必存在漏網明文 $m^* \notin S(c)$ 使得 $\Pr[C=c \mid M=m^*] = 0 \neq \Pr[C=c]$，矛盾成立！
