一、 練習一 6 大核心考點精華與記憶骨架

將 29 道題目精煉成極簡考點，每題只記一句核心因果與破題關鍵

考點模組 1 涵蓋：練習一 1, 14, 15, 16, 27, 28, 29
Ch. 1-2 完善保密與空間邊界

夏農保密本質、金鑰下界與群論 OTP 條件

考點 A：保密的本質是「分佈獨立」，不是長度

（練習一 1, 15）OTP 安全是因為「不論明文是誰，密文分佈恆等於均勻雜訊」（$\Pr[C=c \mid M=m] = 2^{-n}$）。
金鑰長度很長只是必要條件，全零金鑰等長但毫無安全性。在博弈中，攻擊者猜對勝率精確等於硬幣的 $\frac{1}{2}$（$\mathbf{Adv} = 0$）。

考點 B：夏農金鑰下界定理 $|K| \ge |M|$

（練習一 29）若金鑰比明文少（$|K| < |M|$），由抽屜原理，任何密文最多只能解出 $|K|$ 種明文。明文空間內必有漏網之魚 $m^*$ 是該密文解不出來的，產生 $\Pr[C=c \mid M=m^*] = 0$，保密性當場矛盾破裂。

考點 C：模 n 乘法 OTP 必須是「質數」

（練習一 27, 28）乘法 OTP $C = (K \cdot M) \bmod n$：
若 $n$ 為合數，必有零因子相乘為 0（例如 $2 \times 5 \equiv 0 \pmod{10}$），運算不封閉；且明文為 5 時密文永遠只有 0 或 5，$\Pr[C=1 \mid M=5]=0 \neq \Pr[C=1 \mid M=1]=\frac{1}{9}$。
唯有 $n$ 為質數時，每個元素皆具唯一乘法逆元素，密文才能均勻分佈！

考點 D：工程上的 OTP 必然是災難

（練習一 14, 16）1TB USB 隨身碟方案必死三大因：
1. 同步衝突：雙向發送撞車，同一段密碼本被用兩次（Two-time pad 洩漏差分）；
2. 物理殘留：Flash 的 Wear Leveling 機制使邏輯覆寫無法抹除物理位元；
3. 擴展性崩潰：$N$ 個人互通需 $O(N^2)$ 隨身碟，快遞無法即時補給。

考點模組 2 涵蓋：練習一 2, 3, 17, 19
Ch. 2 函式庫黑箱模型與證明手法

黑箱約束、死碼消除與混淆證明（Hybrid Argument）

1. 黑箱權限邊界

（練習一 2, 3）在 Library/Program 模型中，程式絕不可直接讀取內部變數。兩函式庫「可互換」的充要條件是：介面相同，且外在 I/O 聯合機率分佈完全不可區分，內部程式碼長什麼樣完全無所謂。

2. 死碼與未洩漏隨機變數

（練習一 17）$L_A$ 抽 $y$ 回傳；$L_B$ 抽 $y$ 又抽 $z$ 但只回傳 $y$。
結論：完全不可區分。因為 $z$ 取樣後從未被存取，未改變系統全域狀態，邊際機率分佈嚴格恆等。

3. 混淆論證（Hybrid Proof）

（練習一 19）證明 $(X, X \oplus 1^n) \equiv (Y \oplus 1^n, Y)$：
構造中間庫 $L_{\text{hyb}}$ 先抽 $Y$，令 $X'=Y \oplus 1^n$。利用 OTP 均勻性與代數消除 $(Y \oplus 1^n) \oplus 1^n = Y$ 兩步證明完備等價。

考點模組 3 涵蓋：練習一 4, 5, 6, 20, 21
Ch. 4 計算安全界限與統計衝擊

可忽略函數、生日開根號效應與差異引理（Bad Event）

考點 A：可忽略函數與計算安全性實務意義

（練習一 4, 20）可忽略函數定義：$\forall c > 0, \mu(\lambda) < \frac{1}{\lambda^c}$，比任何多項式倒數收斂更快（$2^{-\lambda}$ 是，$1/\lambda^{10}$ 不是）。
計算安全性的意義：突破夏農下界，允許以 256 位元短金鑰加密無上限資料，支撐整個現代網際網路。

考點 B：生日界限「開根號」與雜湊長度加倍

（練習一 5, 21）在大小 $N = 2^n$ 的空間中，取樣次數達到： $$q \approx \sqrt{2 \ln 2 \cdot 2^n} \approx 1.177 \times 2^{n/2}$$ 即有 50% 機率撞期。因此想抵抗 $2^{128}$ 運算量之攻擊，雜湊長度必須至少是 $2 \times 128 = 256$ 位元（SHA-256）！

考點 C：差異引理核心（Bad Event Lemma）

（練習一 6）兩函式庫在極罕見的壞事件（Bad Event）發生前行為百分之百一模一樣。攻擊者的區分優勢上限嚴格受限於壞事件機率： $$\mathbf{Adv} = |\Pr[D^{\mathcal{L}_1} = 1] - \Pr[D^{\mathcal{L}_2} = 1]| \le \Pr[\text{bad}]$$

考點模組 4 涵蓋：練習一 7, 10, 22, 23, 30, 31
Ch. 5-7 偽隨機原語（PRG / PRF / PRP）

PRG 展開、PRF 黃金法則、Switching Lemma 與零輸入漏洞

考點 A：PRG vs PRF 的本質差異

（練習一 7, 22）PRG 是自來水管，只能「循序產生長串流」；PRF 支援「任意指數級輸入空間之隨機存取」（查表式點對點加密）。

考點 B：PRF 黃金法則與自變數抵消漏洞

（練習一 10, 31）黃金法則：同金鑰下絕不可輸入重複值！
（練習一 31）$H(K, X) = F(K, X) \oplus F(K, 0^n)$：輸入 $0^n$ 時恆有 $H(K, 0^n) = F(K, 0^n) \oplus F(K, 0^n) = 0^m$。真隨機命中機率僅 $2^{-m}$，單次查詢 0^n 即可攻破！

考點 C：PRP vs PRF 與 Switching Lemma

（練習一 23）PRP 是雙射（絕無碰撞）；PRF 依生日悖論約取樣 $2^{n/2}$ 必現碰撞。依 Switching Lemma，當查詢量 $q \ll 2^{n/2}$ 時碰撞機率可忽略，PRP 可直接當作 PRF 使用。

考點 D：PRG 反饋型構造安全分水嶺

（練習一 30）內部狀態種子 $s_i$ 嚴格隱藏：安全（用 Hybrid 歸納證明）；若輸出包含中間種子 $s_i$：不安全（本地重算 $G(s_i)$ 比對秒破）。

考點模組 5 涵蓋：練習一 8, 9, 32
Ch. 7 Feistel 區塊密碼架構

幾何結構可逆性、2 輪差分破壞與線性輪函數任意輪數必破

1. 幾何可逆性

（練習一 8）Feistel 恆為置換的原因：解密運算完全無需輪函數 $F$ 本身可逆。每輪透過右半部反饋 XOR，依賴 XOR 自反性自然抵消，輪函數哪怕是常數函數，整體依然可逆。

2. 2 輪 Feistel 必破

（練習一 9）輸入右半部相同時（$R_A = R_B$），第一輪輸出相同： $$L_{2,A} \oplus L_{2,B} = L_A \oplus L_B$$ 密文左半差分恆等於明文左半差分，假置換當場被拆穿。

3. 線性輪函數任意輪必破

（練習一 32）若 $F(K_i, X) = K_i \oplus X$，仿射複合仍為仿射：$C = A \cdot P \oplus B(K)$。取 4 筆輸入 $P_1 \oplus P_2 \oplus P_3 \oplus P_4 = 0$，密文和必為 0。不論迭代多少輪必破！

考點模組 6 涵蓋：練習一 11, 18, 24, 33
Ch. 8 選擇明文安全（CPA）與隨機化

洩漏邊界、決定性加密必死定理、隨機數暴露與空間約束定理

考點 A：CPA 允許洩漏且只允許洩漏「長度」

（練習一 11）CPA 安全模型要求挑戰明文等長（$|M_0| = |M_1|$），此設計明確體現了現代加密允許且不可避免洩漏明文長度 $|M|$。

考點 B：決定性加密必破 CPA 定理

（練習一 24）決定性加密對相同明文必產出相同密文。區分器加密 0 兩次，比對密文是否相等，優勢 $\mathbf{Adv} = 1 - 2^{-|C|} \approx 1$。

考點 C：$|M|=|C|$ 且正確之加密絕不可能達 CPA

（練習一 33）正確性保證單射；有限集單射且 $|M|=|C|$ 必然為雙射；雙射保證每個明文對應唯一密文，故必然為決定性加密；決定性加密必破 CPA。矛盾！

考點 D：隨機數明文暴露無效性與修復

（練習一 18）密文 $(R, K \oplus R \oplus M)$：攻擊者計算 $C_1 \oplus C_2 = K \oplus M$，隨機數 $R$ 自身相消。
修復法：改為 $(R, F(K, R) \oplus M)$，以 PRF 非線性阻斷差分。

二、 考場作答必備：5 大秒殺極簡形式證明範本

剔除冗長廢話，考場直接默寫這 3-4 行算式，拿滿所有推導步驟分數

證明 1：夏農金鑰長度下界定理（$|K| \ge |M|$） 練習一 29 / Ex 2.14
1. 反證法假設：設方案正確且具備完善保密性，但 $|K| < |M|$。
2. 解密空間受限：取合法密文 $c$。令 $S(c) = \{\text{Dec}(k, c) \mid k \in K\}$。因 $\text{Dec}$ 為確定性函數，$|S(c)| \le |K| < |M|$。
3. 鴿籠原理抓漏洞：必存在某明文 $m^* \notin S(c)$。由正確性，$m^*$ 加密絕不可為 $c$，故： $$\Pr[C = c \mid M = m^*] = 0$$
4. 導出矛盾完成證明：完善保密要求 $\Pr[C=c \mid M=m^*] = \Pr[C=c] > 0$，算式衝突矛盾！故必有 $|K| \ge |M|$。
證明 2：$|M|=|C|$ 且正確方案絕不可能達 CPA 練習一 33 / Ex 8.11
1. 正確性要求單射：$\text{Dec}(K, \text{Enc}(K, M)) = M \implies \text{Enc}(K, \cdot)$ 必為單射映射。
2. 有限集單射即雙射：在同基數有限集合下（$|M| = |C|$），單射必為雙射（Bijection）。
3. 必然為決定性加密：雙射表示每個明文有且僅有唯一密文，加密演算法不可能具備隨機性，必然為確定性。
4. 決定性必破 CPA：區分器查詢 $M=0$ 兩次，比對密文是否相同，以優勢 $\mathbf{Adv} \approx 1$ 攻破。矛盾！
證明 3：線性輪函數 Feistel 任意輪數必破 練習一 32 / Ex 7.4
1. 仿射線性複合性質：輪函數 $F(K_i, X) = K_i \oplus X$ 為仿射線性。Feistel 迭代 $r$ 輪後整體滿足： $$C = A \cdot P \oplus B(K)$$ 其中 $A$ 為固定公開可逆矩陣，$B(K)$ 為金鑰偏置。
2. 4 點差分抵消：選取 3 筆相異明文 $P_1, P_2, P_3$，令 $P_4 = P_1 \oplus P_2 \oplus P_3$（故 $\bigoplus_{i=1}^4 P_i = 0$）。
3. 優勢計算：計算 4 密文之 XOR 和： $$\bigoplus_{i=1}^4 C_i = A \left(\bigoplus_{i=1}^4 P_i\right) \oplus \bigoplus_{i=1}^4 B(K) = A(0) \oplus 0 = 0$$ 真實密碼滿足率為 1；真隨機置換命中率為 $2^{-2w}$。優勢 $\approx 1$，任意輪數皆破。
證明 4：自變數抵消 PRF 零輸入秒破 練習一 31 / Ex 6.9
1. 鎖定零輸入致命弱點：對於構造 $H(K, X) = F(K, X) \oplus F(K, 0^n)$，代入 $X = 0^n$： $$H(K, 0^n) = F(K, 0^n) \oplus F(K, 0^n) = 0^m \quad (\text{恆成立})$$
2. 建構區分器演算法： - 查詢 Oracle 得到 $Y := \text{Eval}(0^n)$。 - 若 $Y == 0^m$ 輸出 1；否則輸出 0。
3. 優勢計算： $$\Pr[D^H = 1] = 1, \quad \Pr[D^{\text{Rand}} = 1] = 2^{-m}$$ $$\mathbf{Adv} = |1 - 2^{-m}| \approx 1 \quad (\text{不可忽略，證明完畢})$$
證明 5：模 n 乘法 OTP 達成完善保密性之「質數充要條件」 練習一 27, 28 / Ex 1.15, Ex 2.13
1. 合數必然失敗：若 $n$ 為合數，必有因數分解 $n = a \cdot b$（$1 < a, b < n$）。若明文取 $M = a$，金鑰取 $K = b$，密文 $C = (a \cdot b) \bmod n = 0 \notin \{1, \dots, n-1\}$，連群運算都不封閉；且當明文包含因數時，密文僅能取因數倍數，分佈極不均勻，必破保密性。
2. 質數必然保密：若 $n$ 為質數，集合 $\mathbb{Z}_n^\times = \{1, \dots, n-1\}$ 在模乘法下構成階數為 $n-1$ 的有限阿貝爾群。對任意明文 $m \in \mathbb{Z}_n^\times$，皆存在唯一乘法逆元素 $m^{-1} \pmod n$。
3. 唯一解導出均勻性：同餘式 $K \cdot m \equiv c \pmod n$ 在群中存在唯一解 $K \equiv c \cdot m^{-1} \pmod n$。因為 $K$ 均勻選自 $\{1, \dots, n-1\}$： $$\Pr[C = c \mid M = m] = \Pr[K = c \cdot m^{-1} \bmod n] = \frac{1}{n-1}$$ 條件機率恆為 $\frac{1}{n-1}$，與明文完全無關，達成嚴格完善保密性。故 $n$ 為質數為充要條件。
